The original Prisme Variable Test font is a small MIT-licensed test fixture
created for this repository, with original polygonal H glyphs and two axes.
It is loaded only in Rust tests and is not offered in the production font list.
`work/make-font-fixtures.py` records its nine-master construction and generates
independent FontTools SVG references. No Windows font or glyph is redistributed.

`experience-v17.prisme` is the original generated experience test project
frozen on 27 October before the v18 implementation. It contains an original
bitmap fixture and editable text, not a personal photo. SHA-256:
`40cd64f5e25ab038f4936413e133770ccd356f01ac780ee9b257734af35388e6`.
